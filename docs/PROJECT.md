## 1. Executive summary

SACB is the **L1 software verification core** for the KYREXIS SOVEREIGN stack. It provides:

- Deterministic **Merkle audit** (SHA3-256) with chain integrity checks
- **ML-DSA-65 interface** with explicit simulation fallback (`real_liboqs=false` until liboqs is present)
- **43-agent registry surface** (static registry, not concurrent live processes)
- Claims/evidence boundaries (L0–L4) and promotion rules
- CI verification workflow and Merkle seal script

This repository is **not** a claim of hardware-proven NFC, biometric TEE, photonic loops, or production post-quantum cryptography without liboqs.

## 3. Architecture

```
┌────────────────────────────────────────────────────────┐
│                    SACB Verification Core               │
├─────────────┬──────────────┬──────────────┬────────────┤
│ Merkle Audit │ Agent        │ ML-DSA-65    │ Manifest   │
│ (SHA3-256)   │ Registry     │ Interface    │ Seal       │
│              │ (43 surface) │ (sim/liboqs) │            │
└──────┬───────┴──────┬───────┴──────┬───────┴─────┬──────┘
       │              │              │             │
       ▼              ▼              ▼             ▼
  Integrity     Static IDs     sign_merkle_   audit/
  verify +      + risk         root + status  manifest.json
  leaf chain    tiers
```

- **Merkle**: append-only leaves, pair hashing, root rebuild, chain + root integrity.
- **Registry**: pure data surface (quantum / orchestration / execution / security / monitoring / specialized / junction).
- **ML-DSA**: simulation by default; status reports `real_liboqs=false`.
- **Seal**: `scripts/github_commit.sh` walks tracked sources, computes SHA3-256 root, writes `audit/manifest.json`.

## 4. Cryptography

### 4.1 Merkle audit (`crypto/merkle_audit.py`)

- Leaf content: `event_id`, `timestamp`, `event_type`, `actor`, `payload`, `prev_leaf_hash`
- Hash: SHA3-256 of canonical JSON
- Tree: binary pair hashing; odd node duplicated
- `verify_integrity()`: checks prev-hash chain and root consistency
- `log_event()`: convenience append + truncated root feedback

Evidence level: **L1** (unit-tested, deterministic structure).

### 4.2 ML-DSA-65 interface (`crypto/ml_dsa65.py`)

- Simulation key material derived from `os.urandom(32)` via SHA3-512
- `sign` / `verify` / `sign_merkle_root(fold="FE-OGUF-P1")`
- Explicit fields: `algorithm: "ML-DSA-65-sim"`, `real_liboqs: false`
- Status: `{"runtime": "simulation", "ready": true}`

Evidence level: **L1** (interface + simulation boundaries). Production claim requires real liboqs and L3/L4 promotion.
